# Data analyst capability statement

Confirmed by Keerthi 2026-09-14. This is the plain statement of what he can do in the data and analytics lane, written to be used directly: resume bullets, cover letter paragraphs, screening question answers, LinkedIn headline and about section. The graded matrix lives at `claude/skill-matrix/lane-05-data-analytics.md`.

Target roles: junior data analyst, data analyst, business intelligence analyst, BI developer, reporting analyst, analytics analyst, insights analyst, business systems analyst, data operations analyst, data quality analyst.

## The one-paragraph version

Data analyst with an end-to-end toolkit: SQL for querying and shaping data, Python with pandas and NumPy for cleaning and analysis, Power BI with DAX for modelling and dashboards, and Excel with Power Query for the work that never leaves a spreadsheet. Comfortable across the full path from pulling data out of an API through cleaning, analysis and visualisation to a recommendation a business owner can act on. Background running a digital agency where reporting on campaign performance to non-technical clients was a weekly requirement, and building automation pipelines that move and transform data between systems on a schedule.

## The one-line version

SQL, Python, Power BI and Excel, with a background in API data pipelines and client-facing performance reporting.

## What he can do, by area

**SQL.** SELECT, JOIN across multiple tables, GROUP BY with aggregations, CTEs for readable multi-step queries, subqueries, window functions, CASE expressions for conditional logic, and date functions for period comparisons and time-series work.

**Excel.** Pivot tables, XLOOKUP, INDEX and MATCH, SUMIFS and conditional aggregation, charting, data cleaning, and Power Query for repeatable import and transform steps.

**Power BI.** Building the data model and relationships, DAX measures and calculated columns, dashboard design, filters and slicers, drill-through pages, KPI cards, and Power Query for the transformation layer.

**Python.** pandas for manipulation and analysis, NumPy for numerical work, matplotlib for visualisation, and general data cleaning and exploratory analysis. Backed by production Python across automation pipelines rather than only notebook work.

**Statistics.** Central tendency and spread, distributions, variance, correlation, confidence intervals, and hypothesis testing, applied to deciding whether a difference in the numbers is real.

**Business analytics.** Defining and tracking KPIs, trend analysis, variance analysis against target or prior period, and root-cause analysis when a number moves.

**Data cleaning.** Handling nulls, removing and reconciling duplicates, correcting data types, identifying and deciding what to do about outliers, and standardising inconsistent categorical values.

**Data visualization.** Choosing the chart that answers the question rather than the one that looks impressive, and presenting the finding so the point is clear without narration.

**Data storytelling.** Turning an analysis into a recommendation with a business consequence attached, which is the part most junior analysts skip.

**Supporting.** Git and GitHub with documented projects and version control. Pulling JSON and API data and transforming it, which is the daily substance of the automation work. PostgreSQL and MySQL fundamentals.

## Resume bullets, ready to use

- Query and analyse data with SQL, including CTEs, window functions and multi-table joins, to answer business questions and build reporting datasets.
- Build Power BI dashboards end to end: data model, DAX measures, KPI cards, filters and drill-through, with Power Query handling the transformation layer.
- Clean and analyse data in Python with pandas and NumPy, handling nulls, duplicates, type errors, outliers and inconsistent categories before analysis.
- Report campaign and business performance to non-technical stakeholders, translating metrics into recommendations they can act on.
- Build and operate automated data pipelines that pull from APIs, transform JSON and move data between systems on a schedule.
- Maintain analysis and automation projects in Git with documented READMEs.

## Screening question answers

**"Rate your SQL."** Comfortable with joins, aggregations, CTEs, subqueries and window functions, and with using SQL to build the dataset an analysis or dashboard runs on. Happy to do a live exercise.

**"Do you know Power BI or Tableau?"** Power BI, including the data model and DAX rather than just the visual layer. Tableau I have not used, and the concepts carry over, so I would expect a short ramp rather than a long one.

**"What is your Python experience?"** pandas, NumPy and matplotlib for analysis, and production Python outside analytics for automation pipelines that run on a schedule and handle API data.

**"Have you worked with large datasets?"** Be specific to the truth of the situation rather than reaching. The honest frame is agency and pipeline scale, not enterprise warehouse scale, and it is better said plainly than implied otherwise.

**"Why data analysis?"** The automation work meant moving and reshaping other people's data constantly, and the client reporting meant explaining what it meant. Doing both made analysis the part worth specialising in.

## What not to claim

Machine learning modelling, cloud warehousing on BigQuery or Snowflake, dbt, Tableau, and R. All are currently outside the toolkit by his own ordering, and a posting hard-requiring any of them as a prerequisite is a drop rather than a stretch.

## The gap worth closing

These capabilities are self-assessed rather than employer-verified, which is normal when entering a lane and does not stop applications going out. What closes the distance is one public repo containing a cleaned dataset, a documented SQL query set, and a Power BI or matplotlib output, so a hiring manager can check the claim instead of taking it on trust. Junior analyst screens are practical more often than conversational, so the portfolio and the live-exercise readiness are the same piece of work.
